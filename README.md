# Audiology Portal

## Project Overview
The **Audiology Portal** is a web-based management system developed for the **ICF Hospital** during a Web Development internship at the **ICF IT Centre**. The application digitizes and automates hospital administrative workflows by managing patient records for individuals requiring hearing aids, tracking device issuance, and systematically processing financial reimbursement claims to eliminate manual paperwork and maintain a secure audit trail.

---

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Local Server / Environment:** Apache (via XAMPP / WAMP)
* **Development Tools:** Visual Studio Code, Git & GitHub

---

## Key Features
* **Patient Management:** Secure registration, tracking, and record maintenance for ICF Hospital audiology patients.
* **Device Issuance Tracking:** Digital logging and inventory management for hearing aid machines allocated to eligible individuals.
* **Reimbursement Processing:** End-to-end workflow for submitting, verifying, and approving patient financial reimbursement claims.
* **Secure Data Handling:** Relational database structuring with MySQL to ensure data integrity, fast retrieval, and persistent record-keeping.
* **Form & Document Generation:** Automated creation and export of patient forms and verification records.

## Getting Started

### Prerequisites
* [XAMPP](https://www.apachefriends.org/index.html) or [WAMP](https://www.wampserver.com/) installed on your machine.

### Installation & Setup
1. Clone the repository:
   ```bash
   git clone [https://github.com/chhatresh19/Audiology-portal.git](https://github.com/chhatresh19/Audiology-portal.git)

Move the project folder into your server directory:

For XAMPP: C:/xampp/htdocs/Audiology-portal

For WAMP: C:/wamp64/www/Audiology-portal

Start the Apache and MySQL modules from your XAMPP/WAMP control panel.

Import your database:

Open http://localhost/phpmyadmin in your browser.

Create a new database and import your .sql file.

Open your browser and navigate to: http://localhost/Audiology-portal
